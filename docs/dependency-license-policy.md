# 依存ライブラリのライセンスポリシー

## 基本方針

外部ライブラリやフレームワークを追加・更新する場合は、実装前または同じ変更内でライセンスを確認します。

採用したライブラリのライセンスが表記や同梱を要求する場合は、対象アプリケーションの`THIRD_PARTY_NOTICES.md`や`licenses/`など、配布物から追跡できる場所に必要な記述を追加します。

## 事前確認が必要なライセンス

MIT LicenseまたはApache License 2.0以外のライセンスを含むライブラリやフレームワークを使う場合は、追加前にユーザーへ確認します。

依存先にさらに別ライセンスのパッケージが含まれる場合も同様に確認し、採用可否と必要な表記を明確にしてから実装します。
