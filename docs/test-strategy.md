# テスト戦略

## テストの目的

テストでは、ドキュメントAPI契約、Chromeリーダーの振る舞い、将来のFlutterモバイル経路を保護します。初期提供対象はChrome Web体験なので、最初の優先度はChromeでの動作に置きます。

## バックエンドテスト

バックエンドテストでは次を確認します。

- `GET /health`
- ログイン済みユーザーの識別とロール判定
- 管理者ユーザーだけがドキュメントをアップロードできること
- 一般ユーザーがドキュメントをアップロードできないこと
- 一般ユーザーがアップロードAPIを直接呼び出しても拒否されること
- PDF、JPG、PNG、WebP、EPUB、ZIPのアップロード検証
- 非対応ファイル形式の拒否
- ドキュメント一覧の並び順
- ドキュメント一覧がユーザーの閲覧可能ジャンルで絞り込まれること
- 年齢制限または閲覧レベルが不足するユーザーに制限付きジャンルのドキュメントを返さないこと
- 設定値の保存と取得
- ファイル保存場所メタデータの保存と取得
- PDF/JPG/PNG/WebP/EPUB本文の取得
- 権限外ドキュメント本文の拒否
- ZIPページ一覧の取得
- ZIPページ本文の取得
- 権限外ZIPページ一覧とZIPページ本文の拒否
- 空のZIP、または対応画像を含まないZIPの拒否

テストでは一時ストレージと一時データベースを使います。開発者のローカルアップロードや`library.db`には依存させません。MVPではSQLiteで検証し、MySQL移行時には同じAPI契約をMySQLでも確認できるテストを追加します。

## Chrome Webテスト

Webフロントエンドのテストでは次を確認します。

- ログイン画面の表示と認証状態による遷移。
- ジャンル選択画面の表示と選択状態。
- 管理者ユーザーだけにファイル登録と権限設定の導線が表示されること。
- 管理者ユーザーだけにアップロード画面が表示され、一般ユーザーにはアップロード画面への導線が表示されないこと。
- 一般ユーザーがアップロード画面URLを直接開いた場合に拒否または閲覧可能画面へ戻されること。
- 一般ユーザーに権限外ジャンルのドキュメントが表示されないこと。
- 年齢制限または閲覧レベルが不足するユーザーに制限付きドキュメントが表示されないこと。
- 設定画面の表示と設定変更。
- 設定変更後の再読み込み。
- ドキュメント一覧の読み込み。
- 空状態。
- APIエラー状態。
- PDF、JPG、PNG、WebP、EPUB、ZIPドキュメントの表示。
- ZIPの1ページ表示と2ページ表示。
- 実装後のキーボード操作またはボタン操作によるナビゲーション。

単体テストにはVitestとReact Testing Libraryを使えます。ブラウザレベルの確認には、主対象がChromeであるためPlaywrightを使います。

## Flutterテスト

Flutterテストでは次を確認します。

- ログイン画面の表示。
- ジャンル選択画面の表示。
- 管理者ユーザーと一般ユーザーの表示差分。
- ジャンル別閲覧権限と年齢制限による一覧絞り込み。
- 設定画面の表示。
- ドキュメントモデルのパース。
- 一覧画面の読み込み状態とエラー状態。
- PDF、JPG、PNG、WebP、EPUB、ZIPのビューア遷移。
- APIベースURL設定。
- 設定値の保存と再読み込み。

FlutterはバックエンドAPI契約を再利用します。APIレスポンス形状が変わる場合は、ChromeとFlutterのテストを同時に更新します。

## E2Eスモークテスト

Docker対応後は、Composeで起動したシステムに対して次のスモーク経路を追加します。

1. バックエンドとWebフロントエンドを起動する。
2. バックエンドの`/health`を確認する。
3. 管理者ユーザーでログインする。
4. サンプルドキュメントを投入またはアップロードし、ジャンルと年齢制限を設定する。
5. 一般ユーザーでログインする。
6. 権限内ジャンルの一覧が表示され、権限外ジャンルと年齢制限外ジャンルが表示されないことを確認する。
7. 少なくとも1つのZIPドキュメントを開き、ページ画像が表示されることを確認する。
8. 権限外ドキュメントの本文URLを直接開いても拒否されることを確認する。

## 手動確認

ビューア変更を完了扱いにする前に、次を手動確認します。

- Chromeのデスクトップ幅。
- Chrome DevToolsまたはPlaywrightの狭いモバイル相当幅。
- ログイン画面。
- ジャンル選択画面。
- 管理者ユーザーでのファイル登録導線。
- 管理者ユーザーでのアップロード画面表示。
- 一般ユーザーでアップロード画面とアップロード導線が表示されないこと。
- 一般ユーザーでの権限内ジャンル表示。
- 権限外ジャンルと年齢制限外ジャンルの非表示。
- 設定画面。
- PDFドキュメント。
- 単一JPG/PNG/WebPドキュメント。
- EPUBドキュメント。
- 複数ページのZIPドキュメント。
- 広い画面幅でのZIP 2ページ表示。
