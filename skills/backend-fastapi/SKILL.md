# Backend FastAPIスキル

## 使用する場面

Archiveaの`backend/`配下でFastAPI API、SQLModelモデル、SQLite/MySQL向け永続化、アップロードファイル配信、バックエンドテストを作成・変更する場合にこのスキルを使います。

## 目的

Chrome Webフロントエンドと将来のFlutterクライアントが共通利用するAPIを、FastAPIで小さく検証しやすい単位で維持します。MVPではSQLiteを利用しつつ、MySQLへ移行しやすいモデルとクエリを優先します。

## 外部ライブラリとライセンス

バックエンドで外部ライブラリやフレームワークを追加・更新する場合は、`docs/dependency-license-policy.md` に従います。実装前または同じ変更内でライセンスを確認します。採用したライブラリのライセンスが表記や同梱を要求する場合は、`backend/THIRD_PARTY_NOTICES.md`や`backend/licenses/`など、配布物から追跡できる場所に必要な記述を追加します。

MIT LicenseまたはApache License 2.0以外のライセンスを含むライブラリやフレームワークを使う場合は、追加前にユーザーへ確認します。依存先にさらに別ライセンスのパッケージが含まれる場合も同様に確認し、採用可否と必要な表記を明確にしてから実装します。

## 実装方針

- API契約を先に明確にし、WebとFlutterで重複したドキュメントモデルを増やさない。
- アップロードされたファイル実体はファイルシステムに保存し、保存場所、MIME type、拡張子、並び順などのメタデータはDBに保存する。
- SQLite固有の機能へ寄せすぎず、MySQL移行時に流用しやすいSQLModelモデルとクエリを優先する。
- 振る舞いを変更した場合は、近い場所にテストまたは再現しやすい確認手順を追加する。
