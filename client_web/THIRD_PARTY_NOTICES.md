# Third Party Notices

Archivea Web Client uses the following third-party libraries.

## pdfjs-dist

- Package: `pdfjs-dist`
- Version: `5.7.284`
- Project: https://github.com/mozilla/pdf.js
- License: Apache License 2.0
- License text: `licenses/pdfjs-dist-LICENSE.txt`

`pdfjs-dist` is used to render PDF pages inside the Archivea web reader so the application can control page-by-page and two-page spread behavior without delegating rendering to Chrome's built-in PDF viewer.
